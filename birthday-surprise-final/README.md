# Birthday Surprise Website

Updated interactive birthday website using HTML, CSS and JavaScript.

New interactions:
- Make Your Cake catch-and-stack game with four falling layers + candle
- Slide to blow the candle
- Fruit-Ninja-style knife swipe to cut the cake
- More personal, less generic messages
- Messages reveal progressively instead of all appearing at once
- Final birthday letter uses a keyboard-style typing animation

Run locally by opening `index.html` or using the included `START WEBSITE.bat`.
Deploy the folder to Vercel as a static site.
